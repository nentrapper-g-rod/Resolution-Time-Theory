# origin/ — Founding record (frozen)

This folder is the **preserved founding record** of the original Time Resolution Theory (TRT) vision (Version 2.4, 2025).

It is **archival and intentionally frozen**. Do not edit, narrow, “improve,” or correct these files in later cleanup passes. They are a historical anchor so the starting point stays legible no matter how the live repository evolves.

**Live, tested work** lives in the repository root, `paper/`, `simulations/`, `docs/`, and `CLAIM_MAP.md`.  
**Current status** of original claims is tracked in `ORIGIN.md`’s dated overlay and in `VALIDATION.md` — not by rewriting files here.

## Contents

| File | Role |
|------|------|
| `ORIGIN.md` | Genesis record: seed, metaphors, original scope, core vs scaffolding, dated status overlay |
| `TRT_v2.4_original.pdf` | Primary typeset source — original paper, Version 2.4, as written |
| `TRT_v2.4_original.tex` | Archival LaTeX wrapper + Section 1 text extract (full paper is the PDF) |
| `TRT_v2.4_section1_extract.txt` | Plain-text extract of the Version 2.4 introduction |
| `LAYMANS_ORIGINAL.md` | Plain-language explanation of the **original** vision (not the later narrowed RTT guide) |

Every file in this folder records the original vision **as first proposed**, not validated results.
