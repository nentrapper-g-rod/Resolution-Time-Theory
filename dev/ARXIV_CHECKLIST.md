# arXiv checklist (quant-ph)

Use only after the **fork decision** is settled and the corresponding write-up matches the Claim Map.

- [ ] Primary file is `paper/RTT_Core_Edition_4.1.tex` (or successor)
- [ ] Compiled PDF opens; figures render
- [ ] Abstract does not over-claim (no “replaces QM”; no universal geometric-kernel prediction under present law)
- [ ] Claim Map / VALIDATION status matches the paper
- [ ] LICENSE and CITATION.cff present
- [ ] No process / tool names in the paper text
- [ ] N-12 premises and scoped conclusion stated if gate comparison is mentioned
- [ ] Open problems named: multi-particle, Wallstrom, Lorentz, distinct event law (if still Missing)

Upload source + figures + PDF per arXiv help. Endorsement may be required for first-time quant-ph submitters.
